# TaskAPI

REST API для управления задачами. 

## Технологии

C# / .NET 9 - реализация API.

ASP.NET Core Minimal API - HTTP-эндпоинты.

PostgreSQL - хранение задач.

Entity Framework Core - работа с базой данных и миграции.

RabbitMQ - асинхронная публикация событий о завершении задач.

Docker - запуск RabbitMQ.

xUnit - интеграционное тестирование.

## Функциональность

Создание задачи (по умолчанию незавершенная, со средним приоритетом) с проверкой названия (не пустой, не больше 200 символов) - POST /tasks.

Получение списка всех задач - GET /tasks.

Завершение задачи с фиксацией даты и времени - PUT /tasks/{id}/complete. Если задача не найдена, возвращается 404 Not Found. Если задача уже завершена, возвращается 409 Conflict. После завершения задачи в фоновую очередь добавляется событие для публикации в RabbitMQ.

Публикация события task.completed в RabbitMQ. Публикация выполняется в фоновом обработчике. Если RabbitMQ недоступен, ошибка записывается в лог, а завершение задачи в базе данных сохраняется. Внутренняя очередь приложения хранится в памяти. При аварийном завершении приложения до отправки события сообщение может быть потеряно.

Удаление задачи - DELETE /tasks/{id}. При успешном удалении возвращается 204 No Content. Если задача не найдена, возвращается 404 Not Found.

## Запуск

### Настройка PostgreSQL

Создайте базу данных TaskAPIDb в PostgreSQL. Замените пароль в строке подключения на свой или используйте User Secrets. В папке проекта:
```
dotnet user-secrets init

dotnet user-secrets set "ConnectionStrings:DefaultConnection" "Host=localhost;Port=5432;Database=TaskAPIDb;Username=postgres;Password=ВАШ_ПАРОЛЬ"
```

Замените ВАШ_ПАРОЛЬ на пароль пользователя PostgreSQL.

### Запуск RabbitMQ

Запустите RabbitMQ с панелью управления:

```
docker run -d --name taskapi-rabbitmq -p 5672:5672 -p 15672:15672 rabbitmq:4-management
```

Панель управления доступна по адресу http://localhost:15672. Учетные данные по умолчанию: guest / guest.

### Миграции базы данных

Из папки основного проекта выполните:

```
dotnet ef database update
```

Если команда dotnet ef не найдена, установите инструмент EF Core:

```
dotnet tool install --global dotnet-ef
```

### Запуск приложения

Из папки основного проекта выполните:

dotnet run

Используйте адрес, указанный в выводе приложения.

### Тестирование

Интеграционный тест находится в проекте TaskAPI.Tests.

Тест создает задачу через API, завершает ее и проверяет получение соответствующего события из RabbitMQ.
